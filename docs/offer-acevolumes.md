## Value equation, run on us

- **Dream outcome:** a website that wins clients' trust before the first
  call and keeps generating enquiries while they run the business.
- **Perceived likelihood:** ✅ 100+ sites since 2016, named case studies,
  founder's face on the founder page. No account-manager roulette.
- **Time delay:** ✅ stated "weeks, not months" energy; ⚠️ consider a
  concrete promise ("first preview within 10 days") if we can always keep it.
- **Effort & sacrifice:** ✅ "logo files + photos + 1 hour" already on site.

The weak leg is **time delay**: it's implied, never numbered. Numbering it
is the single highest-leverage copy change available.

## The offer, stated in one line

> AceVolumes builds websites and systems that make results easier — the
> founder builds it himself, you spend one hour, and it's live in weeks.

## Value stack (name everything; currently unnamed on the site)

1. **Founder-built guarantee** — David personally builds it; no handoffs. ✅
2. **The Trust Blueprint** — discovery → sitemap → copy draft, delivered as
   a written plan you keep even if we never build. 💡 new package name.
3. **Speed-record launch** — sub-2-second pages, zero third-party scripts
   (true: verified in production), SEO baked in from commit one. ✅+
4. **The 1-Day Reply Rule** — every message answered within one working
   day, US-first timezones. ✅ already promised; keep.
5. **Launch + 30-day tuning** — launch is the start: we watch the analytics
   (our own first-party tracker) and tune for 30 days. 💡 new.
6. **The Care Plan** — hosting, updates, small changes, monthly report.
   ⚠️ needs pricing decision — this is the recurring revenue line.

## Three tiers (⚠️ pricing is David's call — shapes proposed)

| Tier | What | Shape |
|---|---|---|
| **Launch** | the website, the stack above, 30-day tuning | current core offer; deposit + milestones |
| **Growth** (the yes) | Launch + Care Plan + quarterly conversion review | adds the recurring line; price ≈ Launch + care |
| **System** | Growth + a custom system (CRM/dashboard/portal à la HCMG Command) | premium anchor; quote per system |

Anchor against: a site that loses every visitor it paid to get. Never
discount; move scope between tiers instead.
